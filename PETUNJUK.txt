UPDATE SI-PASAR

1. Cadangkan folder proyek dan database terlebih dahulu.
2. Extract ZIP perbaikan, lalu salin folder/file di dalamnya ke folder proyek SI-PASAR. Pilih Replace jika diminta.
3. JANGAN timpa file .env, database/database.sqlite, atau folder storage milikmu.
4. Dari CMD/Terminal di folder proyek jalankan:
      php artisan config:clear
      php artisan route:clear
      php artisan view:clear
      php artisan migrate
   Jangan gunakan migrate:fresh karena akan menghapus data.
5. Login sebagai Admin/Toolman, buka menu Akun, lalu setujui pengajuan siswa.
6. Tes pendaftaran dan pelaporan foto di HP serta laptop/komputer.

Catatan kamera:
- Kamera browser memerlukan HTTPS, kecuali localhost.
- Jika kamera tidak dapat diakses atau izinnya ditolak, SI-PASAR akan membuka pemilih file/folder sebagai alternatif.
- Format bukti yang diterima: JPG/JPEG, PNG, GIF, BMP. WebP tidak diterima.
